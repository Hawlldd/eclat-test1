# Peaceful Woods

Peaceful Woods foi importada da ROM de Éclat Pourpre a partir do mapa original do grupo 1, mapa 0, preservando o layout de 78×78 células, o tileset secundário comprimido, paletas, metatiles e atributos de colisão.

## Conteúdo implementado

- ligação bidirecional com os dois warps de Route 2;
- quatro warps do mapa, mantendo as saídas norte reservadas para a continuação futura;
- encontros terrestres com a tabela extraída da floresta;
- objetos visuais, Pidgeot/Pidgey, NPCs, placas, itens e textos principais;
- três treinadores com equipes importadas e scripts de vitória;
- seção de mapa `MAPSEC_PEACEFUL_WOODS` e layout independente.

As saídas para a área posterior ainda permanecem dentro de Peaceful Woods até que o mapa seguinte seja portado; isso evita enviar o jogador para uma área Hoenn incompatível.
